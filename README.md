# Sakshi Kolur — Portfolio

A responsive personal portfolio for a Java Full Stack Developer.

## Files
- `index.html` — portfolio content and project links
- `style.css` — responsive styling
- `script.js` — small UI enhancements

## Projects linked
- Employee Management System: https://github.com/sakshi-kolur/Employee-Management-System
- Spotify WebPage: https://github.com/sakshi-kolur/Spotify-WebPage
- E-Commerce: https://github.com/sakshi-kolur/E-Commerce/tree/master

## Run locally
Open `index.html` in a web browser. Google Fonts and Phosphor icons use external CDN resources, so those enhancements need an internet connection.
